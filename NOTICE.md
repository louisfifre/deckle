## Lexical data

The autocorrect module (`Deckle.Input.Autocorrect`) ships compact derived
lexicons under `src/Deckle.Input.Autocorrect/Data/`, regenerated by the
CLI `build-data` command from these sources. The licenses apply to the
data files, not to Deckle's code.

### Lexique 3.83

- Project : http://www.lexique.org — New, Pallier, Brysbaert et al.
- License : CC BY-SA 4.0 (the data).
- Used as : source of French inflected forms and frequencies, reduced to
  the derived `lexicon-fr.tsv.gz` (form + occurrences per million). The
  derived file remains under CC BY-SA 4.0 with this attribution.

### Norvig ngrams (`count_1w.txt`)

- Source : https://norvig.com/ngrams/ — Peter Norvig, derived from the
  Google Web Trillion Word Corpus (Thorsten Brants, Alex Franz, LDC).
- License : free to use per the source page.
- Used as : English word counts behind the bilingual guard, reduced to
  the derived `lexicon-en.tsv.gz`.

### Wikipédia in French

- Source : https://fr.wikipedia.org — plain-text article extracts.
- License : CC BY-SA 4.0 (the text).
- Used as : training and evaluation corpus for the contextual pair model;
  only the derived aggregate `pair-bigrams-fr.tsv.gz` (counts, no
  article text) is versioned, under CC BY-SA 4.0 with this attribution.
