# Glossary

> Not reviewed.

### Category

A group of projects that the user creates and names.

### Main script

The pinned script that the user can start without opening its project.

Avoid: [action](../GLOSSARY.md#action).

### Pinned script

A script of a project's script menu that the user keeps at hand for that project.

### Project

A folder of the user's computer that holds one piece of their work, added to the product so that they can follow it.

### Script menu

The menu, kept in a project, that lists its scripts and runs the one the user chooses, in a terminal.

### Terminal

A program where the user types commands, and where a script runs and writes what it does.

### Uncommitted change

A change to a file of a project that is not yet recorded in the project's history.

### Version

The number a project gives to a state of its work, so that one release can be told from another.
