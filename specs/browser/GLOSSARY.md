# Glossary

> Not reviewed.

### Ad

Content a site shows to sell something on behalf of others, and the requests that bring it.

### Address field

The field at the top of the navigation where the user types an address or words to search, and that shows the domain of the site they are on.

### Media card

The card that shows what a web page plays, such as a video or music, with its controls.

### Pinned site

A site the user keeps as an icon at the top of the navigation, always in the same place, whatever tab they are on.

Avoid: [tab](#tab).

### Site

What the user reaches under one domain, such as « example.com ».

### Tab

One web page open in the window, listed in the navigation under « New Tab », which the user can show, move or close.

Avoid: [pinned site](#pinned-site).

### Web page

What a site shows in the card beside the navigation.

Avoid: [page](../GLOSSARY.md#page).
