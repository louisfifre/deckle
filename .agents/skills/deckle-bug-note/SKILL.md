# Deckle — Bug note

Record one concise, sanitized note near the tests that own the behavior. Follow the repository's existing conventions.

Capture what triggered the bug, what was observed, why it happened, what invariant failed, and what to watch if it returns. State facts plainly and keep uncertainty explicit.

Only record the note. Do not change code or tests unless asked.
