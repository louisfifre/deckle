# Sentence judge bug notes

## Releasing a judge shut ONNX Runtime GenAI down for the whole process

- **Trigger:** A rebuild of the autocorrect runtime while the app runs, which releases the loaded sentence judge and loads a new one. Turning a lexical domain pack on or off in Settings does it. Turning autocorrect off and back on also does, by reading the code, but no crash from that path was seen.
- **Observed symptom:** The app died at once, with no managed exception and no log line from Deckle. The Windows event log showed an access violation (0xC0000005) in `OgaCreateModelFromConfig`, under `OnnxSentenceScorer.CreateModel`. It happened twice, on 2026-10-23 and 2026-11-07, each time just after an `EngineStopped` from autocorrect. The supervisor relaunched the app. The retained logs hold no reload in a running process that succeeded.
- **Cause:** Each `OnnxSentenceScorer` created its own `OgaHandle` and disposed of it on `Dispose` and on a failed load. In Microsoft.ML.OnnxRuntimeGenAI 0.13.0, the `OgaHandle` constructor calls nothing native, while its `Dispose` and its finalizer call `OgaShutdown`. That call destroys the library's state for the whole process. The next `Model` construction then read freed state. Established three ways: by reading the package's IL; by an isolated repro that crashes on DirectML and on CPU once a handle is released, and loads fine while one handle stays alive; and by the regression test, which crashed the test host before the fix. Which global is freed exactly comes from the library's design and was not read in its native source.
- **Violated invariant:** ONNX Runtime GenAI's state outlives every judge and every `Model`, until the process ends. The trap and its reason are commented on the configuration field in `src/Deckle.Autocorrect.Onnx/OnnxSentenceScorer.cs`.
- **Recurrence cue:** `new OgaHandle()` or `using var ... = new OgaHandle()` anywhere in the repo, copied from Microsoft's samples. Or an access violation in an `Oga*` native method right after a judge or a probe runtime was released.
- **Regression coverage:** `OnnxSentenceScorerTests.ALoadAfterAnEarlierOneWasReleasedReportsItsOwnOutcome` runs two failed loads in a row on a config whose model file is missing. That reaches model construction without a real model or a GPU. The full rebuild, a real judge released then reloaded on DirectML, is covered only by the gated system tests of the same class, run in sequence.
