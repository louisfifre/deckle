# `metrics/`

Store metric wrappers when the metric belongs to the autoresearch loop itself:
score extraction, comparison, thresholding, or aggregation. Domain metrics such
as WER, hallucination leakage, or ASR looping belong under
`benchmark/asr/lib/metrics/`.
