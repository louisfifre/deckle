# Installing Deckle

Deckle is free, open-source software. Like many open-source apps, it isn't
signed with a paid certificate — so the **first time** you run it, Windows
shows a warning. This is normal, it is **not a virus**: Windows is simply
cautious about software it doesn't recognize yet.

To launch Deckle, **two clicks**, just once:

```
+----------------------------------------+
| Windows protected your PC              |
|                                        |
| Microsoft Defender SmartScreen blocked |
| an unrecognized app from starting.     |
|                                        |
| [1]  More info                         |   <- click here first
|                                        |
|                         [ Don't run ]  |
+----------------------------------------+
                     |
                     v   (a button appears)
+----------------------------------------+
| Windows protected your PC              |
|                                        |
| App:        Deckle-v0.4.0.exe          |
| Publisher:  Unknown publisher          |
|                                        |
| [2]  [ Run anyway ]                    |   <- then click here
|                                        |
|                         [ Don't run ]  |
+----------------------------------------+
```

1. Click **“More info”**.
2. Click the **“Run anyway”** button that appears.

That's it — Deckle starts, and you won't need to do this again.
